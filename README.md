# tenderprop-layer

Front-end files loaded by tenderprop.com through its admin script boxes.
Public: never put keys, customer data or sales packages here. Load files by pinned commit with SRI.

- `demo/home.js`: homepage design demo, shown only on `/?tp_demo=1`. Sample listings.
- `home/`: homepage for all visitors, loaded from Body Scripts. Sample listings until real data is connected.
